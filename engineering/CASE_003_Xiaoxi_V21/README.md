# CASE_003｜Xiaoxi 字幕放大版 v2.1

## 版本决定

- 配音恢复为：`ElevenLabs_Xiaoxi（年轻友好女）`
- 基于原有 33 秒 Xiaoxi 有声成片制作，不改动原音轨。
- 原晓曼版本保留在装修项目归档中，作为历史版本，不覆盖、不删除。
- 画面比例：9:16，人物安全区保持中部留白。

## 字幕调整

- 原片字幕已经烧录在画面内，本版不重新编写字幕文案，也不改变原片时间轴。
- 对原字幕所在区域做垂直 1.5 倍、水平约 1.25 倍的局部放大，再放回底部安全区，保留原口播字幕与辅助字幕的准确同步。
- 只有原片确实出现底部字幕的镜头才启用放大层；检查表、卡片和空镜不加黑色占位条。
- 放大区域避开人物中部安全区，并保留底部品牌脚注；长句由原片的换行方式继续控制。
- `caption_zoom_filter.txt` 是可复用的 HyperFrames/FFmpeg 工程滤镜记录。

## 交付门禁

1. 音频轨必须存在且时长约 33 秒。
2. 画面、原字幕、音频必须来自同一 v2.1 版本。
3. 旧 Xiaoxi 网页版与晓曼终版都保留，入口只切换到本 v2.1 版本。
