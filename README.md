# 智能剪辑网站

公开产品站，提供软件、应用、服务和项目的双轴目录。当前“智能剪辑”项目下有两款独立下载的软件。

## 信息架构

- 按分类：软件（下载安装）、应用（浏览器或手机端直接使用）、服务（面向客户的线上服务入口）。
- 按项目：项目页聚合同一项目下的产品，例如“智能剪辑”包含声听 Local ASR 和 Audio Toolbox Studio。
- 智能剪辑项目页：工具与案例合并展示，案例播放器复用已发布的公开证据素材；Sony 标记为条件验收，Eagle 来源案例标记为内部参考和权利待核。
- 状态边界：本地应用、待公开服务和未验证入口会明确标注，不会把本机地址或未确认链接发布到公网。

## 公开范围

本仓库只包含静态网站和图标。它不包含模型权重、用户音频、日志、运行数据库、DMG、签名材料或内部发布证据。
