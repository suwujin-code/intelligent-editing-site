# VideoClone OS V2

## Dual-core product split

- AI 视频复刻：参考视频分析 → 替换人物/产品主体 → 生成新版本
- AI 口播生成：创建数字分身 → 克隆/提取声音 → 输入口播文案 → 生成口播视频

## Mobile interaction

- Fixed bottom mini-program navigation
- Right-side drawer for extended functions
- One-step-at-a-time creation workspace
- Desktop sidebar retained

## Current boundary

This is a public workflow test build. Files stay in the visitor's browser and generated results are simulated until real providers are connected.
