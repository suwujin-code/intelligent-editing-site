# VideoClone OS V2.1.1 功能回归报告

- 测试日期：2026-08-06
- 测试环境：隔离沙箱 Chromium + Playwright
- 视口：1440×1050、390×844
- 测试总数：35
- 第一轮：23 PASS / 8 FAIL
- 修复后第二轮：35 PASS / 0 FAIL
- 最终结果：**PASSED**

## 第一轮真实缺陷

1. 顶部通知按钮无任何响应。
2. 人物替换切换到产品替换后，错误沿用旧人物素材。
3. 数字分身从照片切换到自拍视频后，错误沿用旧照片。
4. 声音来源从录音切换到视频提取后，错误沿用旧录音。
5. 生成完成后重新进入功能，停留在旧结果，无法创建第二个项目。
6. 项目历史只有静态列表，无法查看结果、再次创作或删除。
7. 生成完成时已经写入历史，“保存到项目”按钮语义与实际逻辑不一致。
8. localStorage 历史数据损坏时，JSON 解析异常会中断整页脚本。

## 已修复

- 补齐通知按钮反馈和未读状态。
- 切换素材类型时清空不兼容的旧文件与预览。
- 生成结果改为点击“保存到项目”后才写入历史。
- 生成完成页增加“再做一个”和“查看历史”。
- 历史项目增加分类筛选、查看结果、再次创作、二次确认删除。
- 增加项目详情弹窗和历史空状态。
- localStorage 增加安全解析、结构归一化和损坏恢复。
- 增加存储失败容错、对象 URL 清理、未知路由保护和图标按钮 aria-label。
