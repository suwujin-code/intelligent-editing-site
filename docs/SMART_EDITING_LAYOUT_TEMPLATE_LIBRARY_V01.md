# 智能剪辑｜抖音口播排版模板库 V1.0

更新时间：2026-08-06  
适用系统：OING / 智能剪辑 / Talking Head + 字幕  
当前状态：可调用的静帧模板基线

## 目的

这套模板服务于“人物后期进入画面”的口播视频。先确定人物安全区，再分配标题、关键词、普通口播字幕和辅助信息的位置；模板只规定信息层级，不绑定某一条素材或某一个主播。

模板只保存静帧参考图和参数，不把视频当模板。成片仍需根据人物脸、手势、产品和画面亮度做一次安全区复核。

## 竖屏基准

画布：1080 × 1920，9:16。  
核心阅读区：横向 72–1008 px。  
人物预留区：默认 x=230–850、y=540–1320；如果人物偏左或偏右，优先移动关键词槽，不移动普通字幕去压人物。

### 字号调用表

| 层级 | 用途 | 推荐字号 | 位置 | 规则 |
|---|---|---:|---|---|
| C4 | 栏目/主题标题 | 88–108 px | 顶部安全区 y=110–350 | 最多两行；不能盖脸 |
| C2 | 核心关键词 | 64–88 px | 人物左右侧或上方 y=380–720 | 一次一个主关键词，最多一个辅助词 |
| C1 | 普通口播字幕 | 48–60 px | 中下方 y=1390–1660 | 每行建议不超过 16 个汉字；不与 C2 同基线 |
| Meta | 章节、来源、状态 | 30–36 px | 顶部或底部边缘 | 只做辅助，不承担主要信息 |
| Data | 关键数字 | 120–180 px | 左/右信息槽 | 数字必须带单位和来源语境 |

字号相对上一版至少放大约 2 倍；实际落版时以“手机首屏无需放大即可读完”为验收标准。如果标题超过两行，先删字或改为章节标题，不用压缩字距解决。

## 模板编号

### T01｜人物居中·上标题下字幕

适合知识口播、教程、验收说明。标题和关键词放在人物上方/侧上方，人物脸和手势中间保持干净，普通字幕落在中下方。

- 主层级：C4 → C2 → 人物 → C1。
- 关键词颜色使用单一荧光色；普通字幕使用白色或浅灰。
- 防水验收、装修知识、读书拆解默认从 T01 开始。
- 静帧参考：`assets/templates/T01_talking-head-top-title.svg`。

### T02｜人物偏侧·侧边关键词卡

适合主播位于左/右侧、需要同时展示产品或屏幕的内容。关键词进入空侧槽，信息卡只解释一个概念，不能变成第二块字幕。

- 主层级：C4 → 人物/产品 → C2 侧卡 → C1。
- 侧卡宽度建议 260–340 px，避免覆盖人物肩线。
- 适合“问题 → 证据”“前后对比”“三点检查”。
- 静帧参考：`assets/templates/T02_side-keyword-card.svg`。

### T03｜结论导向·数据/流程槽

适合品牌广告节奏、自动剪辑解释和需要让观众记住结论的内容。上方先放一个真实数字或三步关系，人物在中间，普通口播字幕在中下方。

- 主层级：C2 数据/流程 → 人物 → C1 → CTA。
- 一屏最多一个主数字、一个单位和一句判断。
- 不用连续数字滚动冒充信息密度；数字出现必须服务口播。
- 静帧参考：`assets/templates/T03_conclusion-data-slot.svg`。

## 调用协议

```text
输入：人物位置、画幅、受众、传播目的、口播文本、关键词、产品/手势禁区
→ 选择 style_id：T01 / T02 / T03
→ 套用字号与安全区
→ 输出一张静帧审核图
→ 通过 Layout Gate 后，才进入 HyperFrames / Remotion 动效和全片渲染
```

禁止直接把上一条视频复制成“模板”。模板调用的是布局参数、字号、颜色层级和动效入口；人物位置、镜头亮度和文字长度每次都要重新检查。

## QA 门槛

- 标题、关键词、普通字幕三层不在同一基线争抢。
- 人物脸、肩、手、产品和屏幕没有被 C1/C2/C4 遮挡。
- 普通字幕单组能在出现时长内读完，且没有上一句残留。
- 1080×1920 导出后缩小到手机宽度，核心字号仍清楚。
- 底部预留平台 UI 区，不把关键文字放到 1700 px 以下。
- 每个模板都保留一张静帧；通过后再保存工程和成片。
