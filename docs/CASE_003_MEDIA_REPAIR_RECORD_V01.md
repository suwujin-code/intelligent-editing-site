# CASE_003｜防水验收视频修复记录

日期：2026-08-06  
案例：卫生间防水验收｜晓曼有声终版  
问题：线上播放器约 8 秒后画面停住，但进度条继续前进。

## 根因

线上 MP4 的容器元数据显示时长约 33 秒，HTTP Range 请求正常，浏览器也能读取进度；但 H.264 视频轨的 NAL 单元损坏。解码检查出现 `Invalid NAL unit size`、`missing picture in access unit`、`partial file` 等错误，所以播放器的时间轴继续走，而视频帧无法继续解码。

这不是手机端 CSS 或播放器控件造成的，也不是单纯的 CDN 缓存问题。

## 正确源文件

- 云端工程目录：`CASE_003_卫生间防水验收｜晓曼有声终版`
- 完整成片：`CASE_003_卫生间防水验收_晓曼有声终版.mp4`
- 完整工程包：`CASE_003_卫生间防水验收_v2.0_完整工程包.zip`
- 声音：VoxCraft / 声刻「主播_知性口播女声_晓曼」

## 修复要求

1. 用正确源文件替换线上损坏的部署副本。
2. 保留站点现有媒体路径，避免删除其他案例或破坏旧部署脚本。
3. 替换后用 `ffprobe` 检查视频/音频时长和编码，再用 `ffmpeg` 完整解码检查。
4. 浏览器端检查首帧、10 秒、结尾和手机端循环播放。

## 结论

本记录与 `SMART_EDITING_LAYOUT_TEMPLATE_LIBRARY_V01.md` 一起归档。以后遇到“进度条在走但画面停住”，先做媒体解码 QA，再调整页面布局。
