这条案例已从“单次混剪”升级为一份可复用的智能导演工作流资产。公开页面只展示成片和制作方法；原始工程、分轨声音、素材与内部 QA 保存在共享云盘归档包中。

- 横屏：`别只经过生活｜智能导演情绪混剪`
- 竖屏：`别只经过生活｜竖屏安全区适配`
- 案例编码：`DIR-MIX-20260819-001`
- 工作流编码：`WF::DIRECTOR-MIX::20260819::V6::DUAL-ASPECT`
- 技能编码：`SKILL::SMART-DIRECTOR::V6::DUAL-ASPECT`

## 归档包内容

1. 横屏母版、横屏 Web 交付版、竖屏 Web 交付版；
2. HyperFrames 排版工程、渲染脚本、字体和音频资产；
3. UMT、选镜、声音层、旁白脚本与版本 QA；
4. 导演立场卡、音乐 cue sheet、字幕政策和复用契约；
5. 双画幅发布说明与线上页面回看记录。

## 使用边界

素材版权、Fish 接口凭证和原始音频不进入公开 GitHub 资产。调用此工作流时，先确认素材授权与平台规格，再按主题、声音、字幕、画幅和 QA 门禁逐项放行。
