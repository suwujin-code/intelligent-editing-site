## 导演立场

**命题：** 时间只负责向前；人要决定什么值得被留下。  
**中心冲突：** 流逝的速度 vs. 主动记录的选择。  
**观众变化：** 从“只是经过”转向“我愿意停一下，把它留下来”。  
**视觉母题：** 城市速度、人物回望、被保存的瞬间、突然停住的动作。  
**情绪终点：** 不是煽情，而是一次带着余韵的主动选择。

## 声画骨架

| 时间 | 叙事动作 | 音乐 / 声音 | 画面 / 文字 |
|---|---|---|---|
| 0–6s | 冷开场提出“时间” | 近心 Fish 旁白，音乐低密度进入 | 小字建立命题，不急于解释 |
| 6–18s | 日常被速度推着走 | 脉冲和密度渐增，保留环境呼吸 | “向后退 / 沉进人群”等动作词 |
| 18–20s | 断裂与失重 | 主音乐抽空，留一个干燥停顿 | “停”独立成视觉事件 |
| 20–30s | 重新靠近、重新记录 | 动机回归，低频与高频同时打开 | “靠近 / 记录 / 救回一秒”随动作推进 |
| 30–35.5s | 观点回收 | 音乐释放后留尾音，不追加新信息 | “把它留下来”成为唯一结尾主张 |

## 文字与排版政策

- 中文大字使用项目内 Source Han Sans / Noto Sans CJK 资产，白色为主、暖黄作为动词强调。
- 文字只承担命题、动作和转折，不替画面写旁白摘要。
- 用换行、停顿、留白和画面遮挡组织节奏；不使用每拍乱飞的装饰动效。
- 18 秒处的“停”是断裂锚点；20 秒后的动词序列是高潮累积。
- 横屏保持电影式横向构图；竖屏不硬裁掉字卡，采用同源柔焦背景 + 16:9 安全画面居中，保证手机观看时主题仍可读。

## 工具链

- HyperFrames：动态排版与画面构图设计。
- Pillow / FFmpeg：确定性渲染、双画幅适配、编码和 QA。
- Fish（Near-Heart Whisper）：旁白音色模板 `VOICE::EMOTION::FISH::NEAR-HEART-WHISPER::001`。
- OING GitHub Pages：公开案例页与分片媒体加载。
- 共享云盘：母版、网页压缩版、工程包、QA 与本工作流存档。

## 复用契约

换素材时只替换 UMT 中的镜头、旁白和音乐 cue；保留“流逝 → 停顿 → 选择 → 留下”的四段情绪结构。先锁主题和声音脊柱，再生成旁白时间码与字幕，最后按平台输出 16:9 / 9:16。双画幅不等于同一文件裁切：竖屏必须复核字幕安全区、主体可读性和高潮构图。
